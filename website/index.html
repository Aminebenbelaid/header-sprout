Privacy policy

Last updated: November 11, 2026 · Header Sprout extension

Your rules stay on your device. Header Sprout has no accounts, advertising, analytics, or publisher-operated cloud backend. The extension does not send your settings or browsing history to its publisher.

What the extension stores

Header Sprout stores the configuration you enter in your browser’s local extension storage:

  • Header names and values, including any tokens or credentials you choose to enter.
  • URL patterns that determine where rules apply.
  • Profiles, enabled rules, and the pause setting.

The extension does not synchronize this information to a cloud service. Header Sprout does not encrypt its local storage and should not be used as a password vault.

How your rules are used

When you save and enable a request-header rule, your browser sends the configured header value to websites whose request URLs match your rule. If you enter an authentication token, those matching websites receive that token. Choose URL patterns carefully.

Response-header rules change headers received by your browser. These modifications provide the development and debugging features you configure. They do not send data to the extension’s publisher.

Header Sprout uses the browser’s declarative network rules. It does not record request bodies, response bodies, browsing history, or traffic logs. Browser-internal and protected pages cannot be modified.

Why website access is needed

HTTP and HTTPS website access allows Header Sprout to modify headers on the URL patterns you choose, including development servers and localhost. The storage permission saves your configuration on your device. No active header rules are included by default.

Imports and exports

Exported JSON files contain your saved profiles and header values, including any credentials you entered. These files remain on your device unless you choose to share them. Review exports before sharing or committing them to a repository.

Importing a configuration stages it in a paused state for review. Save the imported configuration and resume it when ready.

Retention and your controls

Saved settings remain until you change or remove them, clear the extension’s data, or uninstall it. You can delete individual rules and profiles and save the changes. The power button pauses all saved rules immediately.

Uninstalling the extension removes its local extension storage. Exported files are separate and must be deleted separately. A standalone design preview, if used, stores its settings in that preview site’s local storage; clearing that site’s data removes them.

Limited use

Header Sprout uses data only to provide its user-configured header-editing features. It does not sell user data, use it for advertising, transfer it for unrelated purposes, or use it for creditworthiness or lending decisions.

Header Sprout’s use of information received from browser APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.

This privacy page

This page contains no analytics scripts, tracking cookies, forms, or external fonts. The hosting provider may process ordinary web-server request information to deliver the page. That is separate from the extension’s local settings and header rules.

Changes and questions

If the extension’s data handling changes, this policy will be updated. The date above identifies the current version. For questions, use the developer contact information provided on Header Sprout’s browser-store listing.
